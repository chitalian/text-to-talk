# Expo HAS CHANGED

This project targets **Expo SDK 54**, pinned deliberately: the Expo Go build on
the App Store is 54.x, so an SDK 55+ project cannot be opened on a real phone
without a custom dev build. Read the exact versioned docs at
https://docs.expo.dev/versions/v54.0.0/ before writing any code.

Dev server runs in tmux session `ttt` on port 8090 with `--tunnel`.
